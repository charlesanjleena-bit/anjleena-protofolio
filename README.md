# Anjleena Charles — Portfolio

A React + Vite recreation of the soft/pastel portfolio design shown in the Emergent project.

## Run it in VS Code

1. Install Node.js (LTS) if it is not already installed.
2. Extract this ZIP.
3. Open the extracted `anjleena-portfolio` folder in VS Code.
4. Open the VS Code terminal.
5. Run:

```bash
npm install
npm run dev
```

6. Open the local address shown by Vite (usually `http://localhost:5173`).

## Personalize it

Open `src/App.jsx` to change:
- About Me text
- Skills
- Projects
- Education
- Contact email

The supplied `public/profile.jpg` is cropped from the profile photo visible in the screenshot you provided. You can replace it with your original photo while keeping the same filename.

## Build for deployment

```bash
npm run build
```

The production files will be generated in the `dist` folder.
